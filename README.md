# CRUDTareasAPI

CRUD de Usuarios desarrollado con ASP.NET Core Web API, Entity Framework Core y SQL Server.

## Tecnologías utilizadas

- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- Swagger
- C#
- REST API

## Arquitectura del proyecto

- Controllers
- Services
- Repositories
- Models
- Data

## Funcionalidades

-CRUD de usuarios  
-CRUD de tareas  
-Entity Framework Core  
-SQL Server  
-Swagger  
-Arquitectura en capas  

## Cómo ejecutar el proyecto

### Clonar repositorio

```bash
git clone https://github.com/TU_USUARIO/CRUDTareasAPI.git

### Abrir proyecto

Abrir solución en Visual Studio 2022

### Configurar SQL Server

Modificar el connection string en "appsettings.json"

### Ejecutar migraciones

En terminal "update-database"

### Ejecutar proyecto

En terminal "run"

https://localhost:xxxx/swagger
